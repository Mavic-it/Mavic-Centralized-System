# Database Rules

- Define ownership, constraints, indexes, retention, classification, and tenant isolation explicitly.
- Use migrations that are reviewable, repeatable, backward compatible, and recoverable.
- Include backfill limits, transaction behavior, deployment sequencing, validation, and rollback or recovery guidance.
- Use least-privilege roles, parameterized queries, redacted fixtures, and sensitive-data minimization.
- Test constraints, authorization filters, concurrency assumptions, and failure recovery.
