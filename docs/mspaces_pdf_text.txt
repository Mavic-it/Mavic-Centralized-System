 Branch & Multi-Branch Flow 
branches​
├── MAKATI​
└── ORTIGAS​
 
●​
branches table 
●​
branch_id on employees, rooms, inventory and inquiries 
●​
Branch scope on users/roles where required​
 
Employee / 201 File Flow 
HR / Admin​
    ↓​
Create Employee​
    ↓​
Employee Profile​
    ├── Personal Information​
    ├── Employment Information​
    ├── Emergency Contact​
    ├── Government IDs​
    ├── Contract​
    └── Documents​
            ↓​
      Access Controlled​
            ↓​
        Audit Logged 
●​
Normalize the 201 file across related tables. 
●​
Restrict salary, government IDs and confidential HR documents. 
●​
Serve private documents through authorized backend endpoints, not public URLs. 
​
Leave Management Flow 
Employee → File Leave → Manager Review​
                         ├── Reject → Rejected​
                         └── Approve → HR Review​
                                      ├── Reject → Rejected​
                                      └── Approve → Approved → Leave Balance → Notification 
●​
Store dates, leave type, reason, attachment, status and approval history. 
●​
Make approval workflow configurable where possible. 
●​
Audit every approval and rejection.​

Room / Workspace Flow 
Branch → Building → Floor → Room / Workspace​
                         ↓​
                    Availability​
                         ↓​
                    Reservation​
                         ↓​
                   Confirmation​
                         ↓​
                 History / Reports 
●​
Suggested statuses: AVAILABLE, RESERVED, OCCUPIED, MAINTENANCE, INACTIVE. 
●​
Separate room master data from reservation history. 
​
​
Inquiry / CRM Flow 
Customer / Lead → New Inquiry → Assigned Staff → Contacted​
                    → Follow-up → Site Visit / Negotiation​
                    → Converted OR Lost → Reports 
●​
Track source, branch, interested space, requirements, budget, assigned staff, status, notes and follow-ups. 
​
​
Inventory & Asset Flow 
Inventory: Stock In / Stock Out / Transfer / Adjustment / Return / Damaged / Disposed​
Assets: Asset Tag / Serial Number / Assignment / Warranty / Maintenance / History 
Keep consumable inventory separate from trackable assets such as laptops, monitors, printers, routers, access 
points and CCTV equipment. 
​

│              inventory_transactions, assets, asset_assignments, asset_history​

                       PostgreSQL 
Long-term vision: evolve from an internal HR/operations platform into a centralized coworking-space business 
management platform. New branches, employees, rooms, customers and workflows should be added through 
configuration and well-defined modules rather than duplicated applications. 
Implementation principle: Branch is data. Role is permission. Permission determines the action. The database 
remains normalized. Sensitive actions are authorized and audited.
